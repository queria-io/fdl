# Security

Report a vulnerability in fdl or in the FDL specification privately, through GitHub's [private vulnerability reporting](https://github.com/queria-io/fdl/security/advisories/new). Do not open a public issue for it.

Say what is affected (the command, the part of the specification, the version of fdl-cli), how to reproduce it, and what an attacker gains. We reply within a week.

Fixes go out in a patch release of fdl-cli, and the advisory is published once the release is on PyPI.
